# License Guidance

No final open source license has been selected for this project yet.

Before publishing a formal release, choose and add a real license file if the
repo is intended to permit reuse, redistribution, modification, or commercial
use. Common choices include permissive licenses and copyleft licenses, but the
right choice depends on the intended distribution model.

Until a final license is added, treat this repository as visible source content
with no broad reuse rights granted beyond what the hosting platform allows.

## Pre-Release Decision Points

- Decide whether the public repo should allow commercial reuse.
- Decide whether derivatives must remain open.
- Confirm whether paid bundle templates need separate terms.
- Replace this guidance with the final license text once selected.

This file is guidance only and is not legal advice.
