# Assets

This directory is for public-facing README, demo, blog, and video visuals.

## Structure

- `assets/diagrams/` contains rendered or placeholder architecture images.
- `assets/screenshots/` is reserved for sanitized screenshots.

## Rules

- Use sanitized examples only.
- Do not include real public-facing addresses, credentials, keys, tokens, PSKs,
  account data, or private environment details.
- Keep Mermaid source files under `diagrams/` as the canonical editable version.
- Treat rendered images as presentation assets derived from sanitized source.
