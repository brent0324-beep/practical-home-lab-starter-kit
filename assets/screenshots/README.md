# Screenshot Assets

This directory is reserved for sanitized screenshots used in the README, blog
posts, release pages, and walkthrough videos.

## Safe Screenshot Guidance

- Use only placeholder lab values.
- Crop or hide local usernames, shell prompts, browser profiles, and private
  paths.
- Do not show real device configs, inventories, keys, tokens, PSKs, account
  data, or private environment details.
- Prefer screenshots of rendered diagrams, README sections, and validation
  output.

Real screenshots can be added later after review.
