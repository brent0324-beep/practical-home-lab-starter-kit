# Product Roadmap

This repo starts as a free GitHub README and starter kit. It can later support a
paid PDF/template bundle, but the public version should remain useful on its
own.

## Free Public Version

Current goal:

- Clear README landing page.
- Practical Linux host setup notes.
- GNS3 starter workflow.
- Basic Ansible examples.
- Sanitized templates.
- Redaction and validation scripts.

Success criteria:

- A network engineer can understand the lab design in a few minutes.
- The examples are useful without exposing sensitive details.
- The repo builds trust through practical specificity.

## Future Paid Bundle

Possible additions:

- Polished PDF workbook.
- Expanded diagrams.
- Printable checklists.
- More topology scenarios.
- Ansible backup and validation workflows.
- Lab planning worksheets.
- Troubleshooting decision trees.

Claims should stay modest. The bundle can save time and provide structure, but
it should not promise jobs, certifications, income, or guaranteed outcomes.
