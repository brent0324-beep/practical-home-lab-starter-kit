# Repository Boundary Policy

This repository is only for the Practical Home Lab Starter Kit for Network
Engineers. Keep changes focused on public starter-kit content, sanitized
examples, validation scripts, diagrams, and product planning notes for this
project.

## In Scope

- README and public documentation.
- Sanitized templates.
- Basic Ansible examples.
- Mermaid architecture diagrams.
- Video and PDF planning drafts.
- GitHub contribution, issue, and security templates.
- Validation and redaction checks.

## Out of Scope

- Real lab inventories.
- Real device configurations.
- Customer, employer, or production materials.
- Private notes from unrelated projects.
- Files from unrelated repositories.
- Paid product fulfillment files that contain purchaser or account data.

## Safety Boundary

Do not copy files into this repo from private environments unless they are
rewritten as sanitized examples. When in doubt, create a fresh placeholder
example instead of editing a real config.

## Release Boundary

The public repo should stay useful on its own. Product planning files may outline
future paid bundle ideas, but they should not include guaranteed outcomes or
private operational details.
