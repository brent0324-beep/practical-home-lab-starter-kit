# Media Workspace

This directory holds sanitized source and export assets for walkthrough videos,
AI-narrated demos, thumbnails, and supporting screenshots.

Keep raw recordings, edited exports, narration audio, and thumbnail drafts in
their matching folders. Do not store real secrets, public IP addresses, private
keys, tokens, account data, production hostnames, or private environment details
in media assets.

## Folder Map

- `raw/` stores original screen recordings and capture files.
- `edited/` stores final video exports and reviewed work-in-progress renders.
- `audio/` stores generated narration, scratch narration, and reviewed audio
  exports.
- `thumbnails/` stores thumbnail drafts and social preview images.
- `screenshots/` stores sanitized still images used in videos, README updates,
  thumbnails, or social posts.

Before publishing any asset, review it manually and run the repository
redaction checks.
