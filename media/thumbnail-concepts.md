# Thumbnail Concepts

These concepts are starting points for YouTube thumbnails, GitHub social cards,
and launch previews. Keep all visuals sanitized and avoid real environment
details.

## YouTube Thumbnail Concepts

- Topology-first: large lab topology diagram with short text such as
  "Home Lab Starter Kit".
- Terminal plus diagram: clean terminal on one side, simplified topology visual
  on the other.
- Secure lab workflow: README, firewall, SSH, GNS3, and Ansible visual cues in
  one simple composition.
- Before-and-after structure: "Scattered Lab Notes" contrasted with
  "Repeatable Lab Repo".
- Validation-focused: terminal showing sanitized validation commands with a
  clear green success state.

## GitHub and Social Preview Ideas

- Use the repository name as the primary text.
- Include a compact topology image or diagram export.
- Add a small label such as "GNS3 + Ansible + Linux" when space allows.
- Keep text short enough to read on mobile feeds.
- Prefer clean screenshots or generated previews over dense terminal captures.

## Visual Consistency Guidance

- Use the same font family, color palette, and diagram style across thumbnails.
- Keep the repository name or project title in a consistent location.
- Avoid cluttered screenshots, tiny code, and busy browser chrome.
- Use high contrast and generous spacing.
- Keep all labels generic and sanitized.
