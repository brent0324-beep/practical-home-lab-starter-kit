# Content Funnel

The public repo should be useful without requiring a purchase. The funnel is a
trust path, not a pressure path.

## Free Entry Points

- GitHub README landing page with quick-start workflow.
- Blog article adapted from the README.
- Short video showing the lab structure.
- Free lab deployment checklist.
- Sanitized templates and starter scripts that can be copied safely.

## Helpful Calls to Action

- Star or fork the repo.
- Run the validation and redaction scripts.
- Build the first GNS3 topology.
- Use the free deployment checklist.
- Watch the short walkthrough when available.
- Consider a future bundle only if a polished workbook, diagrams, and
  implementation packs would save time.

## Simple Funnel

1. GitHub repo: useful free foundation.
2. Blog article: explains the architecture and workflow in narrative form.
3. Short video: shows the repo, diagrams, and validation checks.
4. Free checklist: helps users deploy the first lab pass.
5. Future paid bundle: optional deeper workbook, diagrams, troubleshooting
   matrix, and Ansible expansion pack.

## Content Themes

- Secure Linux lab host.
- GNS3 topology discipline.
- Ansible for repeatable network checks.
- SSH and firewall hardening.
- Remote access safety.
- Documentation as part of engineering work.

## Boundaries

Avoid claims about guaranteed career outcomes, income, certification success, or
employment. Position the material as a practical organized starting point. The
free repo, blog article, video, and checklist should remain useful without a
paid purchase.
