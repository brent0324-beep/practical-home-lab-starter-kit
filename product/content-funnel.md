# Content Funnel

The public repo should be useful without requiring a purchase. The funnel is a
trust path, not a pressure path.

## Free Entry Points

- GitHub README landing page.
- Blog-style walkthrough based on the README.
- Short video showing the lab structure.
- Sanitized templates that can be copied safely.

## Helpful Calls to Action

- Star or fork the repo.
- Run the validation and redaction scripts.
- Build the first GNS3 topology.
- Join a mailing list for updates if one exists later.
- Consider the future bundle for a more polished workbook and templates.

## Content Themes

- Secure Linux lab host.
- GNS3 topology discipline.
- Ansible for repeatable network checks.
- SSH and firewall hardening.
- Documentation as part of engineering work.

## Boundaries

Avoid claims about guaranteed career outcomes, income, certification success, or
employment. Position the material as a practical accelerator and organized
starting point.
