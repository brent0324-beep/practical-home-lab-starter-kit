# Free vs Paid Scope

The free repo should be genuinely useful. The future paid bundle, if created,
should add polish, depth, and convenience rather than withholding the basic path.

## Stays Free

- Public README and starter workflow.
- Core architecture explanation.
- Linux host setup guidance.
- GNS3 starter notes.
- SSH, UFW, and remote access safety guidance.
- Basic Ansible inventory and read-only playbooks.
- Sanitized templates for common lab files.
- Validation and redaction scripts.
- Release and security contribution guidance.

## Appropriate for a Paid Bundle

- Polished PDF workbook.
- Expanded diagrams and visual topology packs.
- Printable worksheets and checklists.
- Additional lab scenarios.
- More complete Ansible workflow templates.
- Troubleshooting decision trees.
- Guided exercises with answer keys.
- Editable planning documents.

## Boundary

The paid bundle can save time and provide a more guided experience. It should
not imply guaranteed employment, certification results, income, or production
equivalence. The free repo remains a complete public starting point.
