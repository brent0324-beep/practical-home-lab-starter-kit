# GitHub Repo Description

## Short Description

Secure, repeatable Linux-based home lab starter kit for network engineers using
GNS3, Ansible, SSH, UFW, and sanitized documentation workflows.

## About Text

Practical Home Lab Starter Kit for Network Engineers is a free public starter
repo for building a secure, repeatable Linux-based network lab. It includes
architecture notes, Mermaid diagrams, GNS3 guidance, SSH and UFW hardening,
basic read-only Ansible examples, sanitized templates, validation scripts,
release checklists, and planning docs for future PDF/video content.

The repo is designed to help network engineers build a lab they can explain,
rebuild, document, and safely share without exposing real credentials, private
keys, public-facing addresses, account data, or private environment details.
