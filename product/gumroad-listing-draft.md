# Gumroad Listing Draft

## Title

Practical Home Lab Starter Kit for Network Engineers: PDF and Template Bundle

## Short Description

A practical educational workbook and template pack for building a secure,
repeatable Linux-based network engineering home lab with GNS3, Ansible, SSH,
UFW, diagrams, and deployment checklists.

## Long Description

This bundle is designed for network engineers, students, and lab builders who
want a more guided version of the free Practical Home Lab Starter Kit.

It focuses on practical lab workflow: choosing a Linux lab host, documenting the
topology, keeping remote access narrow, using GNS3 for virtual routers and
switches, running Ansible read-only checks first, and validating/redacting before
sharing lab notes.

The material is educational and template-based. It is not a production network
design, not a guarantee of job or certification outcomes, and not a replacement
for vendor documentation.

## Included Files

- PDF implementation workbook.
- Printable deployment checklist.
- Hardware and BOM worksheet.
- SSH and UFW hardening checklist.
- GNS3 planning worksheet.
- Ansible inventory worksheet.
- Troubleshooting matrix.
- Rendered diagram pack.
- Video walkthrough companion notes.

## Who It Is For

- Network engineers building a home lab.
- Students practicing Linux, GNS3, and Ansible workflows.
- Engineers who want cleaner lab documentation.
- Lab builders preparing sanitized public writeups.

## Suggested Starter Price Range

Suggested starter range: $9 to $19 while the bundle is an early educational
template product.

Keep pricing modest until the PDF, screenshots, rendered diagrams, and
worksheets are polished enough to justify a paid bundle.

## Disclaimer

This is educational and template material. It does not include real credentials,
private keys, PSKs, tokens, private configs, account data, production designs,
or guaranteed outcomes.
