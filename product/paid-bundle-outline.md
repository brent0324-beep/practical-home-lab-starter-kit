# Paid Bundle Outline

This is a planning outline for a possible future paid PDF/template bundle. It is
not a guarantee of final contents.

## Positioning

The bundle would help network engineers build the lab faster with a more
polished workbook, editable templates, and guided exercises. The public repo
remains the free foundation.

## Possible Contents

- PDF build guide with screenshots and diagrams.
- Printable host hardening checklist.
- GNS3 project planning worksheet.
- Ansible inventory and playbook templates.
- Change log and troubleshooting templates.
- Expanded lab scenarios for routing, switching, and automation.
- Review checklist for publishing sanitized lab notes.

## Differentiators

- Practical network-engineer workflow.
- Security-first remote access and SSH guidance.
- Repeatable documentation habits.
- Sanitized examples that are safe to adapt.

## Claims to Avoid

- Guaranteed job outcomes.
- Guaranteed certification pass outcomes.
- Guaranteed income outcomes.
- Claims that a home lab is equivalent to production experience.

## Draft Bundle Structure

1. Planning the lab.
2. Building the Linux host.
3. Securing SSH and UFW.
4. Creating the first GNS3 topology.
5. Connecting Ansible.
6. Running read-only validation.
7. Documenting and improving the workflow.
