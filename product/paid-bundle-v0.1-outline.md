# Paid Bundle v0.1 Outline

This is a practical first outline for a future paid PDF/template bundle. The
free GitHub repo remains useful on its own.

## 1. Implementation Workbook

- Lab planning worksheet.
- Host readiness worksheet.
- Management network plan.
- GNS3 project notes template.
- Ansible inventory planning sheet.
- Change log and validation record.

## 2. Printable Checklist Pack

- Hardware selection checklist.
- Linux host setup checklist.
- SSH hardening checklist.
- UFW baseline checklist.
- GNS3 readiness checklist.
- Ansible readiness checklist.
- Sanitization-before-publishing checklist.

## 3. Expanded Diagrams

- Full lab topology.
- Remote access path.
- Management network.
- Ansible control flow.
- Troubleshooting flow.
- Blog and PDF-ready exports.

## 4. Troubleshooting Matrix

- Symptom.
- Likely layer.
- Checks to run.
- Common causes.
- Safe next action.
- Documentation update needed.

## 5. Ansible Expansion Pack

- Config backup workflow.
- Interface summary collection.
- Version and inventory reporting.
- Pre-change validation.
- Post-change validation.
- Local artifact organization.

## 6. Video Walkthrough Companion

- Short launch video script.
- Full walkthrough script.
- Demo sequence.
- Screenshot plan.
- Terminal command list.

## Boundary

The bundle should save time and provide polish. It should not promise jobs,
certification outcomes, income, or production equivalence.
