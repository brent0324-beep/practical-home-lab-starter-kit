# v0.1.0 GitHub Release Draft

## Release Title

v0.1.0 - Practical Home Lab Starter Kit Foundation

## Release Body

This first release establishes the Practical Home Lab Starter Kit for Network
Engineers as a safe, useful public foundation.

It focuses on a secure, repeatable Linux-based lab workflow using GNS3, Ansible,
SSH, UFW, documentation habits, sanitized templates, and local release checks.

## Included

- Public README and quick-start workflow.
- Architecture, topology, Linux host, GNS3, remote access, security, Ansible,
  and troubleshooting docs.
- Mermaid diagrams for lab topology, remote access, and Ansible control flow.
- Sanitized templates for lab inventory, UFW, SSH hardening, and device vars.
- Basic read-only Ansible examples.
- GitHub issue and pull request templates.
- Publication, sanitization, repository-boundary, and release checklists.
- Video walkthrough outline and narration draft.
- Product planning notes for free content and future paid bundle scope.
- Local packaging script for creating a release archive under `dist/`.

## Safety Notes

All examples are sanitized. Do not add real credentials, private keys, PSKs,
tokens, account data, public-facing infrastructure addresses, or private
environment details.
