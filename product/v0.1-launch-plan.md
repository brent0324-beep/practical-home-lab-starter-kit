# v0.1 Launch Plan

This plan is for a small, practical public launch of the starter kit.

## 1. Final Content Review

- Read the README from top to bottom.
- Confirm repo navigation is clear.
- Review every file under `docs/`.
- Review templates for sanitized examples.
- Review product notes for modest claims.

## 2. Validation

Run:

```bash
./scripts/validate.sh
./scripts/redaction-check.sh
bash -n scripts/validate.sh scripts/redaction-check.sh
git diff --check
```

Resolve every issue before release.

## 3. Release Prep

- Update `CHANGELOG.md`.
- Confirm license status.
- Confirm no private local files are staged.
- Create the release commit.
- Optionally tag `v0.1.0` after review.

## 4. Launch Content

Prepare:

- Short GitHub repo description.
- Blog-style post based on the README.
- 3 to 5 minute walkthrough video.
- Social post focused on the practical value of the free repo.

## 5. Feedback Loop

- Ask network engineers what was unclear.
- Track missing examples or confusing setup steps.
- Prioritize fixes that make the free repo more usable.
- Save larger workbook ideas for the future bundle backlog.
