# v0.1 Release Summary

The v0.1 release establishes the Practical Home Lab Starter Kit as a safe,
credible public foundation for network engineers.

## Release Theme

Secure, repeatable, documented lab foundations.

## Reader Outcome

After reading the repo, a network engineer should understand how to:

- Plan a small Linux-based network lab.
- Use GNS3 for virtual routers and switches.
- Keep a private management network documented.
- Use Ansible for read-only validation.
- Apply basic SSH and UFW hardening.
- Keep public examples sanitized.
- Run validation and redaction checks before publishing.

## Public Value

The free repo should be useful without a purchase. It gives readers a structured
starting point, copyable sanitized examples, and clear safety boundaries.

## Future Bundle Foundation

The release also creates a base for a future paid PDF/template bundle by adding:

- Diagram-ready architecture source files.
- Video script and walkthrough structure.
- PDF table of contents draft.
- Product scope and roadmap notes.
- Local release packaging workflow.

## Release Boundary

This is a starter kit, not a production architecture. It does not provide real
device configs, real inventories, secrets, or guaranteed career outcomes.
