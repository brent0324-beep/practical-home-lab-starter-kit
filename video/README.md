# Video Planning

This directory holds walkthrough outlines, AI voiceover drafts, and final
narration scripts for public demo videos.

## Files

- `walkthrough-outline.md` defines the reusable walkthrough structure.
- `ai-voiceover-script-draft.md` is the working AI narration draft.
- `final-walkthrough-v0.1-script.md` is the production script with timing,
  editor cues, and screen-direction references for editing.
- `final-walkthrough-v0.1-narration-only.md` is the clean ElevenLabs and audio
  generation input. It excludes timestamps, editor cues, and screen direction.

Keep scripts concise, educational, and sanitized. Do not include secrets,
private hostnames, public IP addresses, account data, private keys, PSKs,
tokens, or private environment details.
